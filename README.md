# YAFL - Yet another f... language

*This is my final study project for the Compiler Construction course.*

**YAFL** is a statically and strongly typed, general-purpose procedural language compiling to bytecode for a modified version of the provided [VM3](https://github.com/fwheinz/vm3) virtual machine. Designed to explicitly deviate from C-style syntax and semantics, **YAFL** features a unique pipe-based identifier system, base-N numeric literals, and lazy iterator abstractions.

Detailed documentation can be found [here](/doc/build/report.pdf)
