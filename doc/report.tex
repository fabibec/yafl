\section{General Overview}

\texttt{YAFL} is an abbreviation for ”Yet another f... language”, the replacement part for f... can be chosen by the user based on her or his current stance towards the language.
Possible suggestions are: fabulous, fun or frustrating.

\texttt{YAFL} is a compiled language, as it creates bytecode for a slightly modified
version of the provided \texttt{VM3} virtual machine.
Moreover it is a statically typed general purpose language as the included demo programs prove.
